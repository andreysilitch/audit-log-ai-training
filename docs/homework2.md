**Где SDD сэкономит время / силы, где overhead (на реальном проекте)**

Экономия:
- крупные кросс-командные фичи с несколькими консьюмерами — спека снимает повторные обсуждения и фиксирует контракт;
- задачи с дорогими ошибками (миграции, публичные API, security/audit) — стоимость переделки сильно выше стоимости спеки;
- работа с LLM-агентами — без спеки агент молча додумывает и расходится с командой.

Overhead:
- мелкие изменения и багфиксы — писать `requirements.md`/`design.md`/`tasks.md` дольше, чем сделать;
- быстрое прототипирование / спайки, где требования сами по себе меняются каждый день;
- стабильные внутренние модули с одним владельцем — README + комментарии дешевле, чем поддерживать три файла спеки в синхроне с кодом.
